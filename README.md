# Unity Build Launcher for Windows

A lightweight PowerShell launcher for Unity builds. Choose a resolution and display mode before starting the application, without editing shortcuts or typing launch arguments.

## Features

- Select a Unity build using a file picker or enter its full `.exe` path.
- Choose between windowed and fullscreen mode.
- Set the screen width and height.
- Launch directly from the included `.bat` file — no installation required.

## Requirements

Windows with Windows PowerShell and an existing Unity Windows build. Unity Editor is not required.

## Usage

1. Download and extract the repository, or clone it locally.
2. Double-click **`UnityAppsLauncherStartup.bat`**.
3. Click **Browse...** and select your Unity build's `.exe` file.
4. Choose the display mode and resolution.
5. Click **Launch**.

Keep both launcher files in the same folder:

```text
UnityAppsLauncherStartup.bat
UnityAppsLauncher.ps1
```

Keep the Unity build's accompanying files alongside its executable as generated by Unity.

## Launch parameters

| Setting | Default | Argument |
| --- | --- | --- |
| Display mode | Windowed | `-screen-fullscreen 0` or `1` |
| Screen width | 1920 px | `-screen-width <width>` |
| Screen height | 1080 px | `-screen-height <height>` |

For example, **Windowed / 1280 × 720** launches the build with:

```text
-screen-fullscreen 0 -screen-width 1280 -screen-height 720
```

The launcher checks that the selected `.exe` exists and starts it with its folder as the working directory. Display settings applied by the application itself may override the launch options.
